# GpuRoboticsLab

GPU、几何与机器人算法的个人学习和实验仓库。

## 从这里开始

1. 阅读 [当前进度](progress/current.md)，确认今天的起点。
2. 打开 [第一周任务](progress/weekly/week-01.md)。
3. 在 [资料索引](resources/index.md) 找到原始教材；打开指定文件，把文件路径、章节和 PDF 页码告诉 AI。
4. 边读边讨论，在 notes/ 记下自己的解释，在 experiments/ 做小实验。
5. 本次学习结束时更新进度，留下下一次能直接继续的位置。

给 AI 的开场语：

> 先读取 AGENTS.md、progress/current.md 和当前周任务，然后带我开始今天的学习。请先核对资料，再一次讲一个知识点，给我一道理解题，等我回答。

## 文件用途

- AGENTS.md：AI 辅导流程。
- progress/：当前进度、每周任务和复盘。
- resources/：原三年计划、资料位置与版本信息。
- notes/：知识笔记和疑问模板。
- experiments/：可以复现的小实验。

全部计划与已下载资料已迁入本仓库的 resources/：主计划位于 resources/three-year-reading-plan.md，早期阅读路线图和职业规划位于 resources/plans/，教材及配套资料位于 resources/reading_resources/。PDF、压缩包等仍由 .gitignore 排除 Git 跟踪。当前仓库为本地 Git 仓库。
